# ORZ Corne 分體直列鍵盤 (ZMK Firmware)

**本鍵盤本體是購於淘寶「睫毛外設」的 Eyelash Corne 套件。**

> [!WARNING]
> 本鍵盤與標準的 [foostan's Corne (crkbd)](https://github.com/foostan/crkbd) 不同，**無法**與標準的 `corne` 韌體相容。請務必使用本專案的設定或睫毛外設專屬的板級定義來編譯。

---

## 💡 主要設計特點

本配置專為追求高效率輸入、Vim 操作邏輯，以及方便隨時查詢鍵位的開發者設計：

### 1. 左手單手數字鍵盤（左側 Numpad）
在 **Nav&Num 層 (Layer 1)**，左手側配置了完整的九宮格數字鍵盤與基本運算符號（包含 `7/8/9/+`、`4/5/6/-`、`1/2/3/0/.`），力求讓您**僅用左手單手**就能流暢且完整地輸入所有數字，特別適合需要邊看螢幕或滑鼠、邊快速輸入數據的場景。

### 2. Vim HJKL Homerow 導覽
在 **Nav&Num 層 (Layer 1)**，方向導覽鍵被精準定位在右手的 Homerow（基準鍵位列）上：
- `H` 對應 **左 (LEFT)**
- `J` 對應 **下 (DOWN)**
- `K` 對應 **上 (UP)**
- `L` 對應 **右 (RIGHT)**
- `;` 對應 **退格鍵 (Backspace)**
完全符合 Vim 操作邏輯，讓您的雙手不需要離開鍵盤中心位置即可輕鬆進行游標移動。

### 3. 五向搖桿雙重控制
配備的五向搖桿（Joystick）在不同層級下具有完全不同的操作模式：
- **預設層 (Default Layer)**：作為標準的**方向鍵**（上、下、左、右）及 `Left Ctrl`（垂直按壓點擊）。
- **導覽層 (Nav&Num Layer)**：轉換為**滑鼠控制模式**（上/下/左/右控制滑鼠游標移動，垂直按壓點擊為滑鼠左鍵 `LCLK`）。

### 4. 右手螢幕電量圖示化
右手（從屬側）OLED 螢幕以生動的圖示顯示目前剩餘電量百分比，避免突然沒電的尷尬：
- **滿電格 (Frame 1)**：電量 $\ge 70\%$
- **半電格 (Frame 2)**：電量 $40\% \sim 69\%$
- **低電量 (Frame 3)**：電量 $< 40\%$

### 5. 右手螢幕 GitHub 鍵位圖 QR Code
右手螢幕同時常駐顯示本專案 GitHub 倉庫（[orzorzooo/zmk-new_corne](https://github.com/orzorzooo/zmk-new_corne)）的 **QR Code**。當您忘記任何按鍵配置時，只需拿起手機掃描螢幕上的 QR Code，即可立刻連結到 GitHub 查看最新、最完整的鍵位示意圖，免去記憶煩惱！

## ⌨️ 鍵位層級 (Keymap Layers) 詳細說明

本專案配置共包含 4 個層級，透過 `config/eyelash_corne.keymap` 進行精細定義：

### Layer 0: 預設層 `QWERTY` (default_layer)
這是您平時打字的最基礎層，包含了多項精妙的組合與防錯鍵：
- **滑鼠與搖桿**：搖桿預設為方向鍵 `↑` `↓` `←` `→`，中心單擊為 `Left Ctrl`。
- **大拇指多功能鍵**：
  - `td_spc_mo1` (Tap-Dance)：單擊為 `Space`（空白鍵），雙擊並按住可切換至 Layer 1 (Nav&Num)。
  - `ctrl_tab` (Hold-Tap)：按住為切換至 Layer 1 (Nav&Num)，單擊為 `Ctrl + Space`（Mac 下可用於切換輸入法）。
- **Cmd 防錯按鍵機制 (Mod-Morph + Tap-Dance)**：
  為避免在按住 `Cmd` 鍵切換分頁時誤按 `Cmd + Q` 關閉程式，特別設計了防呆機制：
  - 按住 `Cmd` 單擊 `Q` / `W` / `E` 分別會觸發 `Cmd + 1` / `Cmd + 2` / `Cmd + 3`（分頁切換）。
  - 快速雙擊 `Q` / `W` / `E` 才會觸發原始的關閉命令 `Cmd + Q` / `Cmd + W` / `Cmd + E`。
- **Cmd + R 截圖捷徑**：
  - 按住 `Cmd` 單擊 `R` 為原本的 `Cmd + R` (重新整理)。
  - 按住 `Cmd + Shift` 單擊 `R` 則會直接觸發 `Cmd + Shift + 4` (macOS 區域截圖)。
- **符號與修飾 morphs**：
  - `tab_tilde`：單擊為 `Tab`，Shift + 單擊為 `~`。
  - `semi_dqt`：單擊為 `;`，Shift + 單擊為 `"`。
  - `bs_bslh`：單擊為 `Backspace`，Shift + 單擊為 `\`。
  - `td_comma_dun`：單擊為 `,`，雙擊為 `\`。

### Layer 1: 數字與導覽層 `Nav&Num` (lower_layer)
透過按住左手拇指 `td_spc_mo1`/`ctrl_tab` 或右手拇指的 `mo 1` 激活。
- **左手側**：完整數字九宮格（`7/8/9/+`、`4/5/6/-`、`1/2/3/0/.`），專為單手數字輸入設計。
- **右手側**：Vim 風格 Homerow 導覽鍵（`H/左`、`J/下`、`K/上`、`L/右`、`;/Backspace`），以及 `EQUAL` (`=`)、`STAR` (`*`)。
- **搖桿**：轉換為滑鼠控制移動，中心點擊為滑鼠左鍵 (`LCLK`)。

### Layer 2: 符號層 `Symbol` (raise_layer)
透過按住右手拇指的 `mo 2` 激活，提供常用的程式開發符號：
- **左手側**：`` ` ``、`!`、`@`、`#`、`$`、`%`、`^`、`&`、`'`。
- **右手側**：大括號 `{` `}`、中括號 `[` `]`、小括號 `(` `)`、反斜線 `\`、問號 `?`。

### Layer 3: 控制與功能層 `DEV&F` (control_layer)
當您**同時按住** Layer 1 與 Layer 2 時會觸發此層（ZMK Conditional Layers 機制）：
- **功能鍵**：提供 `F1` 至 `F11`。
- **藍牙連線與配對管理**：
  - 左手大拇指：切換至藍牙設定檔 0, 1, 2 (`&bt BT_SEL 0/1/2`)。
  - 右手側：清除所有藍牙配對 (`&bt BT_CLR_ALL`)。

## 🛠️ 韌體編譯與使用說明

1. 建議直接 **Fork** 本倉庫。
2. 進入您 Fork 的專案，點選 **Actions** 選項，啟用並編譯您的 ZMK 韌體。
3. 確保 [`config/west.yml`](config/west.yml) 中引用的 `eyelash_corne` 模組連結仍然有效。編譯時將會自動從該網址下載 `boards/arm/eyelash_corne` 定義檔。

> [!TIP]
> 如果您已有其他的 ZMK 配置倉庫，也可以利用 ZMK 的模組功能（Modules）將本專案直接作為模組引入，而不需要另外叉取（Fork）。詳細可參考 [ZMK Modules 說明文件](https://zmk.dev/docs/features/modules#building-with-modules)。
